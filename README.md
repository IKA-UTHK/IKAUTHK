# IKAUTHK
Ikatan Alumni Universitas Terbuka Layanan Luar Negeri (IKA UTLLN) Hong Kong dibentuk sebagai rumah kebersamaan bagi seluruh lulusan dan mahasiswa aktif Universitas Terbuka yang berdomisili di Hong Kong. Berdiri dengan semangat gotong-royong, organisasi ini menjadi motor penggerak pengembangan potensi intelektual, karier, dan kepedulian sosial.
